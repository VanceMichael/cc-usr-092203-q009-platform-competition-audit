# 经营主体退出协同

协调经营主体退出中的公告、清算、跨部门核验和登记决定。

## 资料约定

`contracts/domain.schema.json` 描述共享资料的字段结构，`fixtures/domain.json` 提供不含真实个人信息的业务样例。读取模块只校验资料边界，不预先实现业务流程。

当前资料反映以下领域事实：

- 退出路径区分为简易注销、普通清算、强制退出和个体工商户停业
- 登记机关看到主体无经营时，税务、社保、法院、债权人和电商平台仍可能存在未结事项
- 公告、债权申报、税费结清、员工权益、诉讼限制、许可证与平台账户处置均须留存记录
- 部门回执重复或迟到只更新对应事项；公告异议、冒名申请、清算组变化和退出撤回必须保留历史
- 已注销主体的恢复须有法定依据；阻断事项清零后形成唯一退出决定，且每个环节允许或拒绝均可解释

## 本地校验

运行项目自带测试可确认样例资料能够被读取，领域标识、版本、参与方、事实和约束均保持完整。仓库不保存账号、密钥、连接串或真实身份资料。
